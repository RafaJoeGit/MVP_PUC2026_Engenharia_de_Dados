# Coleta

## Fonte

A fonte utilizada foi o Inside Airbnb, com dados públicos de anúncios de
hospedagem em São Paulo. O arquivo efetivamente ingerido pelo notebook é
`listings.csv.gz`.

## Arquivos utilizados

-   `listings.csv.gz`

## Ambiente

O processamento e armazenamento foram realizados no Databricks Free
Edition.

## Persistência

Os dados de anúncios foram persistidos no ambiente e utilizados como
base para as etapas Bronze, Silver e posteriores transformações
analíticas.
